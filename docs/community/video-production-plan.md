## 0. 视频定位与结构（3–5 句）

这是一支「问题—原理—上手—边界」四段式的工具介绍片，面向已经用 NapCat 接真人 QQ 号的 AI 玩家，目标是在 7 分钟内让观众不看文档也明白**它是什么、为什么需要、怎么装、能做什么、不能做什么**。全片以录屏和极简图示为主，深色底 + 蓝紫主色 + 绿色状态色，只保留直切与淡入，不堆砌转场和音效。结构：开场痛点（<1 分钟）→ 原理动画 → 功能总览 → 环境与前置 → 安装配置录屏 → 使用与实测 → 适用场景与限制 → 获取方式 → **独立成段的完整免责声明**。

## 2. 视觉与剪辑规范

- **画面**：深色底 `#0b0e14`；主色蓝紫 `#5b9dff / #8b6cff`；状态色：绿 `#39d98a`、黄 `#ffb020`、红 `#ff5c5c`；最多同时出现 3 种颜色。
- **构图**：左上角固定章节标签（① 问题 ② 原理 ③ 功能 ④ 准备 ⑤ 安装 ⑥ 实测 ⑦ 边界 ⑧ 获取）；底部字幕两行内，关键数字用大字卡（如「46 秒」「仅 NapCat」）。
- **转场**：只用直切和 150ms 淡入；禁用炫光、故障、旋转转场；音效全片 ≤3 个。
- **节奏**：每个信息块 15–40 秒；录屏等待段 2–4× 加速并标注「已加速」。
- **打码**：QQ 号、token、个人目录用户名、群聊内容一律打码；**不要出现真实登录二维码**（用示意图代替）。
