## 4. 剪辑建议

- 等待段（二维码生成、扫码）**2–4 倍加速**，加"已加速"角标；
- 关键状态变化（`NAP CAT_NO_WS → QR_WAITING → ONLINE`）用**画中画/放大**圈出来；
- 所有账号信息、token、局域网 IP 打码；
- BGM 用平台免费商用曲库，音量压到 -20dB 以下；
- 视频结尾放 3 秒 GitHub 地址静态图。

## 5. 录制时用到的命令（可直接复制）

```bat
:: 自检
node src\cli.mjs doctor
node src\cli.mjs rehearse

:: 观察（dry-run）
node src\cli.mjs run --mode attach

:: 自动模式
node src\cli.mjs run --mode attach --live

:: 状态（另开一个窗口看）
node src\cli.mjs status
```
