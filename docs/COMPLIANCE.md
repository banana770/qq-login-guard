# 使用须知、免责声明与禁止用途

> 本文不是法律意见。请在使用前阅读；继续使用即表示你理解并同意以下内容。

## 1. 这是什么性质的软件

`qq-login-guard` 是一个**本地**运行的登录态维护工具：

- 它不修改 NapCat / QQ 客户端 / 腾讯服务；
- 它不做协议破解、不伪造设备指纹、不绕过安全验证；
- 它只做三件事：**探测登录态**、**在掉线时驱动本机模拟器里的官方手机 QQ 完成扫码授权**、**通知你结果**。

## 2. 风险自负

- 用第三方协议端（NapCat 等）登录真人 QQ 账号，本身处于腾讯服务条款的灰色地带，**可能导致账号被限制、冻结甚至封禁**；
- 腾讯风控是单方面、无告知、无 SLA 的自动处置，本项目**不保证降低风控、不承诺自愈成功率、不承担任何账号后果**；
- **不要用高价值主号测试**；建议先用小号验证整条链路。

## 3. 仅限本人账号与本人设备

- 只允许恢复**你自己的 QQ 号**在**你自己的设备**上的登录；
- 架构上强制本地闭环，**不提供**代扫、远程扫码、账号租借/共享类能力；
- 把二维码或登录能力提供给他人 = 账号出借，属于违规且可能违法。

## 4. 明确禁止的用途

使用本工具即表示你**不会**将其用于：

1. 他人账号、代登录、账号买卖/租借；
2. 批量加好友、批量私聊、群发营销、引流、刷量；
3. 骚扰、诈骗、冒充、传播违法信息；
4. 多账号矩阵运营（本项目默认单实例单账号，不做矩阵能力）；
5. 绕过腾讯的安全验证（短信验证码、滑块、申诉、设备锁等）；
6. 任何违反当地法律法规或腾讯服务条款的行为。

## 5. 红线（代码层面如何保证）

- 不自动处理短信验证码、滑块、申诉；识别到即**停止并通知**；
- 被风控/限制登录时**不重试**（重试会加重风控）；
- 阅后即焚：扫码成功后立即删除模拟器相册与本地二维码；
- 默认 dry-run，显式 `--live` 才执行动作；
- 按 PID 精准关停，绝不按镜像名杀进程；
- 只删除本工具产生的文件，不清空用户相册。

## 6. 隐私

- 工具只读取：OneBot 状态、二维码文件、NapCat 日志尾部、设备 UI dump（仅登录相关页面）；
- token 建议用环境变量 `QQ_LOGIN_GUARD_TOKEN`，不要提交进 Git；
- 审计日志 `.qq-login-guard/audit.jsonl` 会自动脱敏 token/secret；仍建议不要外发。
